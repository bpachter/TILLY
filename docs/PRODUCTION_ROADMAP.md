# TILLY Production Roadmap

## Phase 0 (Week 1-2): Foundation

1. Create project repo and core docs.
2. Select engine and set coding standards.
3. Define data schemas for events, crew, destinations.
4. Build simulation harness for seeded test runs.

## Phase 1 (Week 3-6): Tactical Vertical Slice

1. Fixed-screen ship combat prototype.
2. Crew movement and subsystem repair.
3. Power routing and damage model.
4. One enemy faction and 5 encounter templates.

Exit criteria:
- Complete combat loop from contact to victory/defeat.

## Phase 2 (Week 7-10): Exploration and Personality

1. Earth -> Mars -> Europa route.
2. Scan and sample recovery loop.
3. Procedural crew generation with modular traits.
4. 25 event cards tied to personality conditions.

Exit criteria:
- Playable run with at least 30 minutes of content.

## Phase 3 (Week 11-14): Cozy Layer + Meta

1. Downtime systems: cooking, hydroponics, personal quarters.
2. Relationship matrix and bond/conflict events.
3. Basic progression unlocks and codex.

Exit criteria:
- Cozy systems measurably impact tactical and exploration outcomes.

## Phase 4 (Week 15-18): Polish + Public Prototype

1. Pixel art style pass and first soundscape pass.
2. UI readability and onboarding tutorial.
3. Balance pass using telemetry and simulation sweeps.
4. Public demo package with feedback form.

Exit criteria:
- Stable public build and clear next milestone backlog.
