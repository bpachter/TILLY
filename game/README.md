# TILLY Game Runtime

This folder contains the Godot runtime project for the playable game.

## Initial Structure

- project.godot: engine project file
- scenes/: gameplay and UI scenes
- scripts/: GDScript logic

## Immediate Runtime Targets

1. Ship tactical scene with fixed-screen layout.
2. Crew assignment and subsystem interaction.
3. Deterministic combat tick loop driven by seeded RNG.
4. Event intake from validated data contracts.
